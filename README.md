# 保险助理

保险顾问的个人客户管理与销售日程工具（中文）。

## 功能

- **今日**：今天的行程、逾期跟进、A 级客户、本月业绩、7 天内生日、实时天气
- **成功宝典（日历）**：周一到周日、7AM–11PM 一屏看完，下面有本周 Open / Present / Follow-up / Closing、成交保单和 NB（ANP）折线图
- **客户**：客户资料（月薪、吸烟、婚姻、家人人数等），优先级 A/B/C
- **会面记录**：分「个人销售」和「招聘」两个模块；选 Closing 时记录 ANP 与保单张数
- **跟进 / 销售管道 / 招聘管道 / 业绩报告**

## 资料存在哪里

网页版（GitHub Pages）的资料**只保存在你自己那部设备的浏览器里**（localStorage），不会上传到 GitHub 或任何服务器，也不会在手机和电脑之间同步。

- 请定期到「每日助理 → 设置」按「下载备份」
- 换设备时，用「从备份恢复」把资料搬过去
- 清除浏览器资料会把 App 里的资料一起清掉

AI 客户摘要、WhatsApp 草稿和每日自动助理只在 claude.ai 版本可用。

## 开发

`app.html` 是原始文件（claude.ai 版本）。修改后执行：

```
node build.js
```

会生成 `docs/index.html`，GitHub Pages 从 `docs/` 文件夹发布。
